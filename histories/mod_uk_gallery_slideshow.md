## [2.5]

### Added

- Initial release
- JP Gallery Slideshow — reads images from a selectable folder and displays them as a UIkit 3 slideshow
- Sorting: Name ASC/DESC, Time ASC/DESC, Random
- Configurable slide limit
- Full UIkit slideshow controls (dotnav, slidenav, animation, autoplay, velocity, ratio, pause on hover, finite)
- Joomla 5/6 Dispatcher pattern with legacy fallback for Joomla 3/4
- Namespace: Joomlaplates\Module\UkGallerySlideshow
- Empty index.html in every folder
