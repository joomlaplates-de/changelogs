# Joomlaplates Changelogs

Hier finden Sie die Versionshinweise zu den Joomla-Templates, UIKit-Modulen und dem UIKit-Plugin von **Joomlaplates**. Die XML-Dateien dokumentieren neue Funktionen, Verbesserungen und Fehlerbehebungen der jeweiligen Versionen.

## Changelogs ansehen

Die Dateien sind nach Produktgruppe sortiert:

| Produktgruppe | Changelogs öffnen |
|---|---|
| Joomla-Templates | [Templates](Templates/) |
| UIKit-Module | [UIKit Module](UIKit%20Module/) |
| UIKit-Framework-Plugin | [UIKit Plugin](UIKit%20Plugin/) |

Öffnen Sie den passenden Ordner und klicken Sie auf die XML-Datei Ihres Produkts. GitHub zeigt den Inhalt direkt an. Unter `<version>` steht die Versionsnummer; die Einträge darunter beschreiben die Änderungen. Die Änderungstexte sind überwiegend auf Englisch.

Beispiele:

- [Surfing-Template](Templates/tp_surfing.xml)
- [Perfect-Template](Templates/tp_perfect.xml)
- [UIKit Slider](UIKit%20Module/mod_uk_slider.xml)
- [UIKit-Framework-Plugin](UIKit%20Plugin/plg_system_uikit4.xml)

Über **Raw** in der GitHub-Dateiansicht können Sie die XML-Datei direkt öffnen oder speichern. Eine Changelog-Datei enthält Versionshinweise; sie ist kein installierbares Template oder Modul.

Die installierbaren Produkt-ZIPs erhalten Sie über den Joomlaplates-Kundenbereich entsprechend Ihrer Downloadberechtigung. Dieses Repository stellt die Changelogs öffentlich bereit.

## Hinweise zu den XML-Dateien

- Jede Produktdatei enthält die Historie der jeweiligen Erweiterung. Bei den Templates ist ein großer Teil der Historie gemeinsam; dokumentierte Ausnahmen bleiben beim jeweiligen Produkt erhalten.
- Die `changelog.xml` in einem heruntergeladenen Produktpaket ist der Stand der Historie bei der Paketveröffentlichung. Die Dateien in diesem Repository werden bei weiteren Veröffentlichungen fortgeführt.
- Die [index.xml](index.xml) ordnet die Produkte für die Changelog-Anzeige zu. Sie muss von Kunden weder installiert noch bearbeitet werden.
- Neue Funktionen, Änderungen, Fehlerbehebungen und Hinweise stehen in getrennten XML-Kategorien. Ein Eintrag unter `security` bezeichnet eine dokumentierte Sicherheitskorrektur.
